# v0.2.1-rc2

- Add support for DSH Desktop **0.2.1-rc.2**, with Cordis **4.0.5** and Schemastery **3.18.5**.
- Retain support for Desktop 0.2.0-rc.2 and 0.2.1-rc.1.
- Update the Codex plugin, Desktop adapter and setup diagnostics.

Task execution continues in the existing Desktop Host, with isolated workspaces and explicit tool permissions. No additional model API key or separate DSH CLI/Web runtime is required.

See the [setup guide](https://github.com/Cryocell77/codex-deepseek-harness-desktop-bridge/blob/v0.2.1-rc2/docs/CODEX-PLUGIN.md) and [validation record](https://github.com/Cryocell77/codex-deepseek-harness-desktop-bridge/blob/v0.2.1-rc2/docs/VALIDATION.md).
